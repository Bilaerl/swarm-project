# Decentralised Reinforcement Learning for Robot Swarm Foraging
This project showcased the use of Decentralised Reinforcement Learning in coordinating a robot swarm towards completing a foraging task.

## Software Stack
- Gazebo Harmonic: For robot simulation
- ROS2 Jazzy: For robot programming
